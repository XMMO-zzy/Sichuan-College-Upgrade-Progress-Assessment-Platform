# 蜀岸 · 2027 四川专升本备考进度测验

依据四川统招专升本考试大纲（**大学英语 / 高等数学 / 计算机基础**）设计的一站式备考工具：
每日测验、多套全真模拟、错题集与自由组卷、知识点详解、6 个月备考计划、学习记录与统计。纯静态网页，**离线可用**，数据保存在本地浏览器。

## 快速开始

**方式一（推荐）：零依赖本地服务**

```
node serve.js          # 默认 http://127.0.0.1:8080/
node serve.js 9000     # 也可指定端口
```

**方式二：直接双击 `index.html`**（推荐 Chrome / Edge）

> 也可用 `python -m http.server 8000` 等任意静态服务器托管本目录。

## 功能一览

| 页面 | 说明 |
| --- | --- |
| **今日任务** | 当日测验清单、阶段/周次定位、距考试倒计时、打卡记录、连续打卡 |
| **每日测验** | 今日任务（自动组题）、全真模拟卷（多套可选）、自选练习（按科目/知识点/难度） |
| **错题集** | 答错自动收录 + 手动加入，支持勾选错题自由组合成一套试卷重做 |
| **备考计划** | 4 阶段 × 28 周 = 180 天的完整计划表，今日所在周高亮 |
| **学习记录** | 三科得分率环图、近 14 天趋势、知识点掌握（薄弱优先）、模拟考试记录、错题数、数据导出 |
| **知识点库** | 全部题目的知识点与解析，支持按科目/关键词检索 |
| **设置** | 考试日期（默认 2027-04-17）、称呼、每日题量强度（轻松/标准/加强） |

## 题目结构与题型

- **英语**：单选（语法 12 大板块）、翻译（**全部为英译汉**）、补全对话、阅读理解、选词填空
- **数学**（高等数学·理工类）：极限与连续、一元微分学、一元积分学、二重积分、常微分方程与级数、**线性代数**（行列式/矩阵/方程组/特征值）；含**计算大题**（答案支持数值与表达式判分，如 `1/3`、`e^2`、`ln2`、`pi/4`）
- **计算机**：基础知识、软硬件系统、操作系统、网络、信息安全、Word、Excel、PowerPoint、数据库、新技术（AI/大数据/云计算等）；含**简答题**与**操作题**（自评判分）

每道题均标注**考察知识点**：作答前**默认隐藏**，提交判分后才显示考点与**详细解析**。
每道题右上角可「＋ 加入错题集」；答错的题目会**自动进入错题集**，重复收录会给出明确提示。

## 全真模拟卷

内置 **3 套**全真模拟卷（可复现、互不重叠为主），每套包含英语（单选 + 英译汉 + 补全对话 + 选词填空，**不含阅读理解**）、数学（单选/填空/计算）与计算机（单选/简答/操作）三科。

## 错题集与自由组卷

- **自动收录**：每日测验、全真模拟、自选练习中判为**答错**的题目自动进入错题集（按科目/知识点分组）。
- **手动加入**：题目右上角点「＋ 加入错题集」；若该题已在错题集中，会提示「该题已在错题集中，无需重复添加」。
- **自由组卷**：在错题集页勾选任意题目（支持全选/清空选择），点「🧩 生成错题试卷」即可自由组合成一套试卷，进入后作答、提交判分并查看解析。
- 支持单题「移除」或一键「清空错题集」（清空不影响学习记录与打卡）。

## 6 个月备考计划

| 阶段 | 天数 | 重点 |
| --- | --- | --- |
| ① 基础巩固 | 1–45 | 数学极限/微分基础；英语核心语法+词汇；计算机基础/软硬件/操作系统 |
| ② 进阶提高 | 46–90 | 数学积分学；英语阅读+选词填空；计算机网络/安全/Excel |
| ③ 强化训练 | 91–135 | 数学二重积分+微分方程+级数+线性代数；英语补全对话+翻译进阶；计算机 Word/Excel/PPT 操作 |
| ④ 冲刺模拟 | 136–180 | 每日全题型模拟 + 周末全真套卷 + 错题复盘 |

每日任务按阶段自动调配各科题型数量与难度，可到「设置」调整题量强度。

## 目录结构

```
├── index.html          入口页面
├── css/style.css       主题样式
├── js/
│   ├── data/           题库（english.js / math.js / computer.js）
│   ├── plan.js         6 个月备考计划（4 阶段 × 28 周）
│   ├── core.js         纯逻辑：选题、判分、数学表达式求值
│   └── app.js          页面渲染与交互
├── serve.js            零依赖本地静态服务器（node serve.js）
└── smoke-test.js       Node 集成冒烟测试（node smoke-test.js）
```

## 数据与隐私

所有学习记录、打卡、错题集与设置均保存在浏览器 `localStorage`，不上传任何服务器；「学习记录」页可一键导出 JSON 备份。
